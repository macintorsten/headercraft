# Example 3: Generated Code Provenance

Enforcing deterministic generated file provenance (`Code generated by ... DO NOT EDIT.`) across Go, TypeScript, and Rust without timestamp churn.

## What this demonstrates
1. **Tool Stamping:** Standard Go `// Code generated ... DO NOT EDIT.` headers are enforced across linters.
2. **Deterministic Outputs:** Omitting dynamic timestamps (`now.*`) ensures code generation remains reproducible and byte-stable in git.
3. **Spec Path Extraction:** Preserves the specific source spec (`api/users.proto`) from existing headers while updating generator version.

## Try it
```bash
headercraft diff --config headercraft.toml before/
headercraft fix --config headercraft.toml before/
```
