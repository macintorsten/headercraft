# HeaderCraft Examples

This directory contains real-world scenarios, complete configurations, and sample test fixtures showcasing HeaderCraft's capabilities.

## Scenarios

| Directory | Scenario | Languages | Key Features |
|---|---|---|---|
| [`01-spdx-migration/`](01-spdx-migration/) | **SPDX Migration** | Go, Python, TypeScript | Migrating legacy verbose copyright boilerplate to compact SPDX tags while preserving original year & author |
| [`02-corporate-confidential/`](02-corporate-confidential/) | **Corporate Confidentiality** | SQL, XML, Java | Proprietary security classification banners with centralized contact info and XML prolog preservation |
| [`03-generated-code/`](03-generated-code/) | **Generated Code Stamping** | Go, TypeScript, Rust | Deterministic `Code generated by ... DO NOT EDIT` provenance without timestamp churn |
| [`04-dual-licensing/`](04-dual-licensing/) | **Dual Licensing** | Rust, C, Python | Dual Apache-2.0 / MIT licensing notices and SPDX expressions |
| [`05-git-pre-commit-hook/`](05-git-pre-commit-hook/) | **Git Pre-Commit Hook** | Go (Live GitHub Clone) | Live Git commit history timestamp extraction, `hk` hook enforcement, and automatic fix on commit |

## Directory Structure
Each example contains:
- `headercraft.toml`: The self-contained configuration for the scenario.
- `before/`: Source files before header application (unheadered or legacy format).
- `after/`: Expected output after running `headercraft fix`.
- `README.md`: Explaining the scenario, template logic, and execution steps.

## Testing an Example
Navigate to any example directory and run HeaderCraft:

```bash
cd examples/01-spdx-migration

# 1. Preview changes as unified diff
headercraft diff --config headercraft.toml before/

# 2. Check violations in GCC format (hk standard)
headercraft check --format gcc --config headercraft.toml before/

# 3. Apply changes in-place
headercraft fix --config headercraft.toml before/

# 4. Verify all files now pass
headercraft check --config headercraft.toml before/
```
