# HeaderCraft Examples

This directory contains real-world scenarios, complete configurations, before/after test fixtures, and runnable pre-commit configurations for HeaderCraft.

Every example directory includes a self-contained `README.md` with **visual Before & After code snippets**, allowing you to understand the behavior directly while browsing GitHub without needing to clone or execute code.

---

## Interactive Scenarios

| Directory | Scenario | Languages | Key Capabilities |
|---|---|---|---|
| [**`01-spdx-migration/`**](01-spdx-migration/) | **SPDX Specification & License Migration** | Go, Python, TypeScript | Migrating legacy verbose legal boilerplate to compact SPDX tags while preserving original inception years and authors |
| [**`02-corporate-confidential/`**](02-corporate-confidential/) | **Corporate Confidentiality & Security Banners** | Java, XML, SQL | Proprietary security classification banners with XML prolog preservation (`<?xml ...?>`) and multi-language comment syntax |
| [**`03-generated-code/`**](03-generated-code/) | **Generated Code Stamping & Provenance** | Go, TypeScript, Rust | Deterministic `Code generated by ... DO NOT EDIT.` provenance without Git timestamp churn, preserving protobuf source paths |
| [**`04-dual-licensing/`**](04-dual-licensing/) | **Open Source Dual-Licensing** | Rust, C, Python | Dual Apache-2.0 / MIT licensing notices and multi-source author attributions |
| [**`05-git-pre-commit-hook/`**](05-git-pre-commit-hook/) | **Live Git-Backed Pre-Commit Hook** | Go (Live GitHub Clone) | Extracting inception years dynamically from real Git commit history (`git log`) and enforcing sub-second `hk` pre-commit hooks |
| [**`06-script-help-sync/`**](06-script-help-sync/) | **Script CLI `--help` Synchronization** | Bash, Shell | Auto-syncing in-code script usage comments with runtime `bash <file> --help` output via command caching |

## Directory Structure

Each example folder is self-contained:
- **`headercraft.toml`**: The exact scenario configuration.
- **`hk.pkl`**: Standard [`hk`](https://github.com/jdx/hk) pre-commit hook definition.
- **`mise.toml`**: Developer runner tasks for [`mise`](https://github.com/jdx/mise).
- **`before/`**: Realistic input files (unheadered or legacy formats).
- **`after/`**: Canonical expected output after running `headercraft fix`.
- **`README.md`**: Explains the problem, visual Before/After diffs, template syntax, and execution commands.

## Quick-Run Recipes

### Option 1: Run via `hk` and `mise` (One-Liner)
```bash
cd examples/01-spdx-migration

# Run pre-commit check using hk
mise exec hk@latest -- hk check --all

# Auto-fix all files in-place
mise run fix
```

### Option 2: Run via Standalone CLI
```bash
cd examples/01-spdx-migration

# 1. Preview changes as unified diff
headercraft diff --config headercraft.toml before/

# 2. Check violations in GCC format (compatible with IDEs and linters)
headercraft check --format gcc --config headercraft.toml before/

# 3. Apply changes in-place
headercraft fix --config headercraft.toml before/

# 4. Verify all files now pass
headercraft check --config headercraft.toml before/
```
