# Security Policy

## Supported Versions

Security updates are provided for the latest minor release:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in HeaderCraft, please report it privately:

1. Use GitHub's private vulnerability reporting feature under **Security > Advisories > Report a vulnerability**.
2. Or contact the maintainer directly via GitHub at [@macintorsten](https://github.com/macintorsten).

Please do not open public issues for suspected vulnerabilities. We will respond promptly to investigate and patch confirmed security issues.
